# OKroddee Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an offline, single-machine web application that replaces a
second-hand car dealership's Google Sheet and hand-written book: clients,
cars, installment contracts, payments, repossession warnings, and a per-car
event timeline.

**Architecture:** One Flask process serving server-rendered Jinja templates
on `localhost`, backed by a single SQLite file. All pure business logic
(money arithmetic, schedule generation, status derivation, validation) lives
in dependency-free modules with pytest coverage; the Flask layer only routes,
queries, and renders.

**Tech Stack:** Python 3.11+, Flask, Jinja2, `sqlite3` (standard library),
pytest. No ORM, no JavaScript build step, no external services.

**Spec:** `docs/superpowers/specs/2026-08-24-okroddee-design.md`

## Global Constraints

- All monetary values are stored and computed as **integer satang**
  (1 THB = 100 satang). Floating-point money is never stored or computed.
  Conversion to a display string happens only in templates.
- All dates are stored as ISO-8601 `TEXT` (`YYYY-MM-DD`). Timestamps are
  ISO-8601 with seconds.
- No network access at runtime. No CDN links in templates, no external
  fonts, no API calls.
- No user accounts, logins, or permissions.
- Interface labels are bilingual (Thai and English) via `lang.py`. Data
  entered by staff is never translated.
- Status values are exactly these strings:
  - `cars.status`: `available`, `on_contract`, `sold`, `repossessed`
  - `contracts.status`: `active`, `completed`, `repossessed`, `cancelled`
  - `car_events.type`: `acquired`, `contract_started`, `contract_completed`,
    `repossessed`, `sold`, `note`
  - derived installment states: `PAID`, `PARTIAL`, `OVERDUE`, `UPCOMING`
  - derived contract flags: `OK`, `OVERDUE`, `REPOSSESS_ELIGIBLE`
- The application never changes a contract's status on its own, except
  marking a contract `completed` when a recorded payment leaves every
  installment paid.

## File Structure

```
app.py            Flask application: routes, request handling, rendering
db.py             Schema, connection, and every SQL query
money.py          Satang arithmetic, schedule generation, status derivation
validate.py       Input validation at the entry boundary
lang.py           Thai/English label dictionary
templates/        base.html plus one template per screen
static/app.css    All styling
test_money.py     pytest suite for money.py
test_validate.py  pytest suite for validate.py
run.command       Launcher: back up the database, then start the server
```

`money.py` and `validate.py` import nothing outside the standard library, so
they are testable without Flask or a database. `validate.py` is an addition
to the spec's file layout: the spec lists validation as a requirement but
gives it no home, and it does not belong in a module named `money`.

Files that change together live together: `db.py` holds both the schema and
the queries against it, so a column change and its readers are one diff.

`money.py`:

```python
"""Money, schedules, and derived contract status.

Every amount in this module is an integer number of satang
(1 THB = 100 satang). Floating-point money is never used.
"""

from decimal import Decimal, InvalidOperation, ROUND_HALF_UP


def to_satang(value):
    """Parse a user-entered baht amount into integer satang."""
    text = str(value).replace(",", "").strip()
    try:
        baht = Decimal(text)
    except InvalidOperation:
        raise ValueError(f"not a valid amount: {value!r}")
    return int((baht * 100).quantize(Decimal("1"), rounding=ROUND_HALF_UP))


def format_baht(satang):
    """Render integer satang as a baht string, e.g. 1540000 -> '15,400.00'."""
    sign = "-" if satang < 0 else ""
    whole, cents = divmod(abs(satang), 100)
    return f"{sign}{whole:,}.{cents:02d}"
```

import calendar
from datetime import date


def generate_schedule(first_due, count, due_day):
    """Return `count` due dates: the first exactly on `first_due`, then
    `due_day` of each following month, clamped to each month's last day."""
    if count < 1:
        raise ValueError("a contract needs at least one installment")
    if not 1 <= due_day <= 31:
        raise ValueError("due_day must be between 1 and 31")

    dates = [first_due]
    for offset in range(1, count):
        months = first_due.month - 1 + offset
        year = first_due.year + months // 12
        month = months % 12 + 1
        last_day = calendar.monthrange(year, month)[1]
        dates.append(date(year, month, min(due_day, last_day)))
    return dates
```

def outstanding(amount_due, late_fee, paid_total):
    """What is still owed on one installment, in satang. May be negative."""
    return amount_due + late_fee - paid_total


def installment_state(amount_due, late_fee, paid_total, due_date, today):
    """One display label for an installment.

    PARTIAL wins over OVERDUE: an installment that is past due and partly
    paid reads as PARTIAL, but still counts toward overdue_count.
    """
    if outstanding(amount_due, late_fee, paid_total) <= 0:
        return "PAID"
    if paid_total > 0:
        return "PARTIAL"
    if due_date < today:
        return "OVERDUE"
    return "UPCOMING"


def overdue_count(rows, today):
    """How many installments are past due with money still owed."""
    return sum(
        1
        for r in rows
        if r["due_date"] < today
        and outstanding(r["amount_due"], r["late_fee"], r["paid_total"]) > 0
    )


def contract_flag(overdue):
    """Translate an overdue count into the dashboard warning level."""
    if overdue >= 2:
        return "REPOSSESS_ELIGIBLE"
    if overdue == 1:
        return "OVERDUE"
    return "OK"


def days_late(due_date, paid_on):
    """Days between the due date and the payment, never negative."""
    return max(0, (paid_on - due_date).days)
```

```python
"""Checks applied where data enters the system."""


class ValidationError(ValueError):
    """Raised when staff input is not acceptable. The message is shown to them."""


def thai_id(value):
    """Return the cleaned 13-digit Thai national ID, or raise."""
    text = str(value).replace("-", "").replace(" ", "")
    if len(text) != 13 or not text.isdigit():
        raise ValidationError("Thai ID must be 13 digits")
    total = sum(int(text[i]) * (13 - i) for i in range(12))
    if (11 - total % 11) % 10 != int(text[12]):
        raise ValidationError("Thai ID checksum is wrong")
    return text


def payment(amount_satang, paid_on, today):
    """Raise if a payment amount or date is not acceptable."""
    if amount_satang <= 0:
        raise ValidationError("Payment amount must be greater than zero")
    if paid_on > today:
        raise ValidationError("Payment date cannot be in the future")
```

"""SQLite schema, connection, and every query in the application."""

import sqlite3
from datetime import date, datetime
from pathlib import Path

DB_PATH = Path(__file__).parent / "okroddee.db"

SCHEMA = """
CREATE TABLE IF NOT EXISTS clients (
  id          INTEGER PRIMARY KEY,
  first_name  TEXT NOT NULL,
  last_name   TEXT NOT NULL,
  thai_id     TEXT UNIQUE,
  phone       TEXT,
  address     TEXT,
  note        TEXT,
  created_at  TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS cars (
  id              INTEGER PRIMARY KEY,
  brand           TEXT NOT NULL,
  series          TEXT,
  model_year      INTEGER,
  color           TEXT,
  plate_number    TEXT UNIQUE,
  registration_no TEXT,
  chassis_no      TEXT,
  mileage         INTEGER,
  cost_price      INTEGER,
  asking_price    INTEGER,
  status          TEXT NOT NULL
                  CHECK (status IN ('available','on_contract','sold','repossessed')),
  note            TEXT,
  created_at      TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS contracts (
  id                 INTEGER PRIMARY KEY,
  client_id          INTEGER NOT NULL REFERENCES clients(id),
  car_id             INTEGER NOT NULL REFERENCES cars(id),
  car_price          INTEGER NOT NULL,
  down_payment       INTEGER NOT NULL DEFAULT 0,
  installment_amount INTEGER NOT NULL,
  installment_count  INTEGER NOT NULL,
  due_day            INTEGER NOT NULL CHECK (due_day BETWEEN 1 AND 31),
  first_due_date     TEXT NOT NULL,
  status             TEXT NOT NULL
                     CHECK (status IN ('active','completed','repossessed','cancelled')),
  note               TEXT,
  created_at         TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS installments (
  id          INTEGER PRIMARY KEY,
  contract_id INTEGER NOT NULL REFERENCES contracts(id),
  seq         INTEGER NOT NULL,
  due_date    TEXT NOT NULL,
  amount_due  INTEGER NOT NULL,
  late_fee    INTEGER NOT NULL DEFAULT 0,
  UNIQUE (contract_id, seq)
);

CREATE TABLE IF NOT EXISTS payments (
  id             INTEGER PRIMARY KEY,
  installment_id INTEGER NOT NULL REFERENCES installments(id),
  paid_on        TEXT NOT NULL,
  amount         INTEGER NOT NULL CHECK (amount > 0),
  method         TEXT,
  note           TEXT,
  created_at     TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS car_events (
  id          INTEGER PRIMARY KEY,
  car_id      INTEGER NOT NULL REFERENCES cars(id),
  event_date  TEXT NOT NULL,
  type        TEXT NOT NULL
              CHECK (type IN ('acquired','contract_started','contract_completed',
                              'repossessed','sold','note')),
  contract_id INTEGER REFERENCES contracts(id),
  note        TEXT
);

CREATE INDEX IF NOT EXISTS idx_installments_contract ON installments(contract_id);
CREATE INDEX IF NOT EXISTS idx_payments_installment  ON payments(installment_id);
CREATE INDEX IF NOT EXISTS idx_car_events_car        ON car_events(car_id);
CREATE INDEX IF NOT EXISTS idx_contracts_client      ON contracts(client_id);
CREATE INDEX IF NOT EXISTS idx_contracts_car         ON contracts(car_id);
"""


def connect(path=DB_PATH):
    conn = sqlite3.connect(path)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON")
    return conn


def init(conn):
    conn.executescript(SCHEMA)
    conn.commit()


def now():
    return datetime.now().isoformat(timespec="seconds")


def as_date(text):
    return date.fromisoformat(text)
```

"""OKroddee: offline dealership management. Run with `python app.py`."""

from datetime import date

from flask import Flask, g, redirect, render_template, request, session

import db
import lang
import money

app = Flask(__name__)
app.secret_key = "okroddee-local-only"  # offline, bound to 127.0.0.1, no sessions to steal


def get_db():
    if "db" not in g:
        g.db = db.connect(db.DB_PATH)
    return g.db


@app.teardown_appcontext
def close_db(exception):
    conn = g.pop("db", None)
    if conn is not None:
        conn.close()


@app.context_processor
def template_globals():
    code = session.get("lang", lang.DEFAULT)
    return {
        "t": lambda key: lang.t(key, code),
        "fmt": money.format_baht,
        "lang_code": code,
        "today": date.today(),
    }


@app.route("/lang/<code>")
def set_language(code):
    session["lang"] = code if code in lang.LABELS else "en"
    return redirect(request.referrer or "/")


@app.route("/")
def index():
    conn = get_db()
    counts = {
        "clients": conn.execute("SELECT COUNT(*) c FROM clients").fetchone()["c"],
        "cars": conn.execute(
            "SELECT COUNT(*) c FROM cars WHERE status = 'available'"
        ).fetchone()["c"],
        "contracts": conn.execute(
            "SELECT COUNT(*) c FROM contracts WHERE status = 'active'"
        ).fetchone()["c"],
    }
    return render_template("index.html", counts=counts)


if __name__ == "__main__":
    with app.app_context():
        db.init(get_db())
    app.run(host="127.0.0.1", port=8000)

def available_cars(conn):
    return conn.execute(
        "SELECT * FROM cars WHERE status = 'available' ORDER BY brand, series"
    ).fetchall()


def list_contracts(conn, status=None):
    sql = (
        "SELECT c.*, cl.first_name, cl.last_name, cars.brand, cars.series,"
        " cars.plate_number FROM contracts c"
        " JOIN clients cl ON cl.id = c.client_id"
        " JOIN cars ON cars.id = c.car_id"
    )
    params = []
    if status:
        sql += " WHERE c.status = ?"
        params.append(status)
    return conn.execute(sql + " ORDER BY c.created_at DESC", params).fetchall()


def create_contract(conn, fields):
    """Insert a contract with its full schedule. Raises ValueError if the car
    is not available."""
    car = get_car(conn, fields["car_id"])
    if car is None or car["status"] != "available":
        raise ValueError("That car is not available")

    dates = money.generate_schedule(
        fields["first_due_date"], fields["installment_count"], fields["due_day"]
    )
    cur = conn.execute(
        "INSERT INTO contracts (client_id, car_id, car_price, down_payment,"
        " installment_amount, installment_count, due_day, first_due_date, note,"
        " status, created_at)"
        " VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, 'active', ?)",
        (
            fields["client_id"],
            fields["car_id"],
            fields["car_price"],
            fields["down_payment"],
            fields["installment_amount"],
            fields["installment_count"],
            fields["due_day"],
            fields["first_due_date"].isoformat(),
            fields.get("note"),
            now(),
        ),
    )
    contract_id = cur.lastrowid
    conn.executemany(
        "INSERT INTO installments (contract_id, seq, due_date, amount_due)"
        " VALUES (?, ?, ?, ?)",
        [
            (contract_id, seq, due.isoformat(), fields["installment_amount"])
            for seq, due in enumerate(dates, start=1)
        ],
    )
    conn.execute("UPDATE cars SET status = 'on_contract' WHERE id = ?", (fields["car_id"],))
    conn.execute(
        "INSERT INTO car_events (car_id, event_date, type, contract_id)"
        " VALUES (?, ?, 'contract_started', ?)",
        (fields["car_id"], date.today().isoformat(), contract_id),
    )
    conn.commit()
    return contract_id

def contract_form_fields(form):
    """Pull contract fields off a submitted form, converting money and dates."""
    try:
        fields = {
            "client_id": int(form["client_id"]),
            "car_id": int(form["car_id"]),
            "car_price": money.to_satang(form.get("car_price") or 0),
            "down_payment": money.to_satang(form.get("down_payment") or 0),
            "installment_amount": money.to_satang(form["installment_amount"]),
            "installment_count": int(form["installment_count"]),
            "due_day": int(form["due_day"]),
            "first_due_date": date.fromisoformat(form["first_due_date"]),
            "note": (form.get("note") or "").strip() or None,
        }
    except (KeyError, ValueError):
        raise validate.ValidationError("Please fill in every contract field correctly")
    if fields["installment_count"] < 1:
        raise validate.ValidationError("A contract needs at least one installment")
    if fields["installment_amount"] <= 0:
        raise validate.ValidationError("The installment amount must be greater than zero")
    if not 1 <= fields["due_day"] <= 31:
        raise validate.ValidationError("The due day must be between 1 and 31")
    return fields

    conn = get_db()

        "cars": db.available_cars(conn),
    }
    if request.method == "POST":
        try:
            fields = contract_form_fields(request.form)
        except validate.ValidationError as error:
            flash(str(error))
            return render_template("contract_form.html", form=request.form, **choices)

        schedule = money.generate_schedule(
            fields["first_due_date"], fields["installment_count"], fields["due_day"]
        )
        if request.form.get("action") == "preview":
            return render_template(
                "contract_form.html",
                form=request.form,
                schedule=schedule,
                amount=fields["installment_amount"],
                **choices,
            )
        try:
            contract_id = db.create_contract(conn, fields)
        except ValueError as error:
            flash(str(error))
            return render_template("contract_form.html", form=request.form, **choices)
        return redirect(url_for("contract_detail", contract_id=contract_id))
    return render_template("contract_form.html", form={}, **choices)

INSTALLMENTS_SQL = """
SELECT i.*, COALESCE(SUM(p.amount), 0) AS paid_total
FROM installments i
LEFT JOIN payments p ON p.installment_id = i.id
WHERE {where}
GROUP BY i.id
ORDER BY i.seq
"""


def _installment_dict(row):
    """Row -> dict with due_date parsed, ready for the money module."""
    return dict(row, due_date=as_date(row["due_date"]))


def get_contract(conn, contract_id):
    return conn.execute(
        "SELECT c.*, cl.first_name, cl.last_name, cars.brand, cars.series,"
        " cars.plate_number FROM contracts c"
        " JOIN clients cl ON cl.id = c.client_id"
        " JOIN cars ON cars.id = c.car_id WHERE c.id = ?",
        (contract_id,),
    ).fetchone()


def installments_for(conn, contract_id):
    rows = conn.execute(
        INSTALLMENTS_SQL.format(where="i.contract_id = ?"), (contract_id,)
    ).fetchall()
    return [_installment_dict(r) for r in rows]


def get_installment(conn, installment_id):
    row = conn.execute(
        INSTALLMENTS_SQL.format(where="i.id = ?"), (installment_id,)
    ).fetchone()
    return _installment_dict(row) if row else None


def payments_for(conn, installment_id):
    return conn.execute(
        "SELECT * FROM payments WHERE installment_id = ? ORDER BY paid_on, id",
        (installment_id,),
    ).fetchall()


def set_late_fee(conn, installment_id, late_fee):
    conn.execute(
        "UPDATE installments SET late_fee = ? WHERE id = ?", (late_fee, installment_id)
    )
    conn.commit()


def add_payment(conn, installment_id, paid_on, amount, method, note):
    conn.execute(
        "INSERT INTO payments (installment_id, paid_on, amount, method, note, created_at)"
        " VALUES (?, ?, ?, ?, ?, ?)",
        (installment_id, paid_on.isoformat(), amount, method, note, now()),
    )
    conn.commit()


def complete_contract_if_paid(conn, contract_id):
    """Close the contract and mark the car sold once nothing is outstanding."""
    rows = installments_for(conn, contract_id)
    if any(
        money.outstanding(r["amount_due"], r["late_fee"], r["paid_total"]) > 0
        for r in rows
    ):
        return False
    contract = conn.execute(
        "SELECT * FROM contracts WHERE id = ?", (contract_id,)
    ).fetchone()
    if contract["status"] != "active":
        return False
    conn.execute("UPDATE contracts SET status = 'completed' WHERE id = ?", (contract_id,))
    conn.execute("UPDATE cars SET status = 'sold' WHERE id = ?", (contract["car_id"],))
    conn.execute(
        "INSERT INTO car_events (car_id, event_date, type, contract_id)"
        " VALUES (?, ?, 'contract_completed', ?)",
        (contract["car_id"], date.today().isoformat(), contract_id),
    )
    conn.commit()
    return True

def contract_view(conn, contract_id):
    """Everything the contract detail page needs, with status derived."""
    contract = db.get_contract(conn, contract_id)
    if contract is None:
        return None
    rows = db.installments_for(conn, contract_id)
    today_ = date.today()
    for row in rows:
        row["outstanding"] = money.outstanding(
            row["amount_due"], row["late_fee"], row["paid_total"]
        )
        row["state"] = money.installment_state(
            row["amount_due"], row["late_fee"], row["paid_total"], row["due_date"], today_
        )
    overdue = money.overdue_count(rows, today_)
    return {
        "contract": contract,
        "installments": rows,
        "overdue": overdue,
        "flag": money.contract_flag(overdue),
    }


@app.route("/contracts/<int:contract_id>")
def contract_detail(contract_id):
    view = contract_view(get_db(), contract_id)
    if view is None:
        return "Not found", 404
    return render_template("contract_detail.html", **view)


@app.route("/installments/<int:installment_id>/pay", methods=["GET", "POST"])
def installment_pay(installment_id):
    conn = get_db()
    installment = db.get_installment(conn, installment_id)
    if installment is None:
        return "Not found", 404
    contract = db.get_contract(conn, installment["contract_id"])

    if request.method == "POST":
        try:
            paid_on = date.fromisoformat(request.form["paid_on"])
            amount = money.to_satang(request.form["amount"])
            late_fee = money.to_satang(request.form.get("late_fee") or 0)
            validate.payment(amount, paid_on, date.today())
        except (KeyError, ValueError) as error:
            flash(str(error))
            return render_template(
                "payment_form.html", installment=installment, contract=contract
            )
        if late_fee != installment["late_fee"]:
            db.set_late_fee(conn, installment_id, late_fee)
        db.add_payment(
            conn,
            installment_id,
            paid_on,
            amount,
            request.form.get("method"),
            (request.form.get("note") or "").strip() or None,
        )
        db.complete_contract_if_paid(conn, installment["contract_id"])
        return redirect(url_for("contract_detail", contract_id=installment["contract_id"]))

    return render_template(
        "payment_form.html", installment=installment, contract=contract
    )

def repossess_contract(conn, contract_id):
    """Close the contract and take the car back. Staff-initiated only."""
    contract = conn.execute(
        "SELECT * FROM contracts WHERE id = ?", (contract_id,)
    ).fetchone()
    conn.execute(
        "UPDATE contracts SET status = 'repossessed' WHERE id = ?", (contract_id,)
    )
    conn.execute(
        "UPDATE cars SET status = 'repossessed' WHERE id = ?", (contract["car_id"],)
    )
    conn.execute(
        "INSERT INTO car_events (car_id, event_date, type, contract_id)"
        " VALUES (?, ?, 'repossessed', ?)",
        (contract["car_id"], date.today().isoformat(), contract_id),
    )
    conn.commit()


def cancel_contract(conn, contract_id):
    """Void a contract entered in error and free the car."""
    contract = conn.execute(
        "SELECT * FROM contracts WHERE id = ?", (contract_id,)
    ).fetchone()
    conn.execute(
        "UPDATE contracts SET status = 'cancelled' WHERE id = ?", (contract_id,)
    )
    conn.execute(
        "UPDATE cars SET status = 'available' WHERE id = ?", (contract["car_id"],)
    )
    conn.commit()

def active_installments(conn):
    """Every installment on every active contract, with who and what it is for."""
    rows = conn.execute(
        "SELECT i.*, COALESCE(SUM(p.amount), 0) AS paid_total,"
        " c.id AS contract_id, cl.first_name, cl.last_name,"
        " cars.brand, cars.series, cars.plate_number"
        " FROM installments i"
        " JOIN contracts c ON c.id = i.contract_id"
        " JOIN clients cl ON cl.id = c.client_id"
        " JOIN cars ON cars.id = c.car_id"
        " LEFT JOIN payments p ON p.installment_id = i.id"
        " WHERE c.status = 'active'"
        " GROUP BY i.id ORDER BY i.due_date, i.id"
    ).fetchall()
    return [_installment_dict(r) for r in rows]


def collected_between(conn, start, end):
    """Satang received between two dates, inclusive."""
    row = conn.execute(
        "SELECT COALESCE(SUM(amount), 0) AS total FROM payments"
        " WHERE paid_on BETWEEN ? AND ?",
        (start.isoformat(), end.isoformat()),
    ).fetchone()
    return row["total"]
```

## Notes for the implementer

- **Money never touches a float.** Parse with `money.to_satang`, store the
  integer, format with `money.format_baht`. If you find yourself writing
  `/ 100` outside `money.py`, stop.
- **Status is derived, never stored.** The only fields written are
  `contracts.status` and `cars.status`, and only by an explicit staff action
  or by `complete_contract_if_paid`.
- **The application never repossesses anything.** It shows
  `REPOSSESS_ELIGIBLE` and waits for a person to click.
- **`conn.commit()` lives in `db.py`.** Routes call query functions; they do
  not write SQL.
- **Offline means offline.** No CDN links, no web fonts, no analytics.
