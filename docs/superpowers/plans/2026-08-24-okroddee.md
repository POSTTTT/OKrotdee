# OKrotdee Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an installable offline desktop application that replaces a
second-hand car dealership's Google Sheet and hand-written book: clients,
cars, installment contracts, payments, repossession warnings, and a per-car
event timeline.

**Architecture:** A Tauri 2 desktop application with a React + TypeScript
interface and a SQLite database in the platform application-data directory.
Every business rule lives in TypeScript; the Rust side is boilerplate that
registers plugins. Pure modules (`money.ts`, `validate.ts`, `schema.ts`) and
the query layer (`db.ts`) are tested with vitest in plain Node; React screens
are verified by hand.

**Tech Stack:** Tauri 2, React 18, TypeScript, Vite, `@tauri-apps/plugin-sql`
(SQLite), vitest, `better-sqlite3` (test-only).

**Spec:** `docs/superpowers/specs/2026-08-24-okrotdee-design.md`

## Global Constraints

- All monetary values are **integer satang** (1 THB = 100 satang). No
  floating-point money anywhere. Parse with `money.toSatang`, display with
  `money.formatBaht`.
- All dates are ISO-8601 `YYYY-MM-DD` **strings**, never `Date` objects, in
  the database, in props, and in the pure modules. ISO strings sort and
  compare correctly with `<` and `>`; that is why they are the currency of
  this codebase. Timestamps are ISO-8601 with seconds.
- No network access at runtime: no CDN links, no web fonts, no analytics,
  no update checks.
- No user accounts, logins, or permissions.
- Interface labels are bilingual (Thai and English) via `lang.ts`. Data
  entered by staff is never translated.
- Status values are exactly these strings:
  - `cars.status`: `available`, `on_contract`, `sold`, `repossessed`
  - `contracts.status`: `active`, `completed`, `repossessed`, `cancelled`
  - `car_events.type`: `acquired`, `contract_started`, `contract_completed`,
    `repossessed`, `sold`, `note`
  - derived installment states: `PAID`, `PARTIAL`, `OVERDUE`, `UPCOMING`
  - derived contract flags: `OK`, `OVERDUE`, `REPOSSESS_ELIGIBLE`
- The application never changes a contract's status on its own, except
  marking a contract `completed` when a recorded payment leaves every
  installment paid.
- `src-tauri/src/lib.rs` registers plugins and nothing else. No business
  logic in Rust. If a task seems to need Rust, it is the wrong task.

**Prerequisite:** the development machine needs Node, Rust, and Xcode
command-line tools, and internet access for `npm install` and `cargo build`.
All four were verified present before this plan was written.

`src/money.ts`:

```typescript
/**
 * Money, schedules, and derived contract status.
 *
 * Every amount here is an integer number of satang (1 THB = 100 satang);
 * floating-point money is never used. Every date is an ISO-8601 string,
 * which compares correctly with < and >.
 */

export type InstallmentState = "PAID" | "PARTIAL" | "OVERDUE" | "UPCOMING";
export type ContractFlag = "OK" | "OVERDUE" | "REPOSSESS_ELIGIBLE";

export interface OverdueRow {
  dueDate: string;
  amountDue: number;
  lateFee: number;
  paidTotal: number;
}

const pad = (n: number) => String(n).padStart(2, "0");

/** Parse a user-entered baht amount into integer satang, rounding half up. */
export function toSatang(value: string | number): number {
  const text = String(value).replace(/,/g, "").trim();
  const match = /^(-)?(\d+)(?:\.(\d+))?$/.exec(text);
  if (!match) throw new Error(`not a valid amount: ${value}`);
  const [, sign, whole, fraction = ""] = match;
  const digits = (fraction + "000").slice(0, 3);
  const satang = Number(whole) * 100 + Number(digits.slice(0, 2));
  const rounded = Number(digits[2]) >= 5 ? satang + 1 : satang;
  return sign ? -rounded : rounded;
}

/** Render integer satang as baht, e.g. 1540000 -> "15,400.00". */
export function formatBaht(satang: number): string {
  const sign = satang < 0 ? "-" : "";
  const absolute = Math.abs(satang);
  const whole = Math.floor(absolute / 100).toLocaleString("en-US");
  return `${sign}${whole}.${pad(absolute % 100)}`;
}

/**
 * Return `count` due dates: the first exactly on `firstDue`, then `dueDay`
 * of each following month, clamped to each month's last day.
 */
export function generateSchedule(
  firstDue: string,
  count: number,
  dueDay: number,
): string[] {
  if (count < 1) throw new Error("a contract needs at least one installment");
  if (dueDay < 1 || dueDay > 31) throw new Error("dueDay must be between 1 and 31");

  const [year, month] = firstDue.split("-").map(Number);
  const dates = [firstDue];
  for (let offset = 1; offset < count; offset++) {
    const months = month - 1 + offset;
    const y = year + Math.floor(months / 12);
    const m = (months % 12) + 1;
    const lastDay = new Date(Date.UTC(y, m, 0)).getUTCDate();
    dates.push(`${y}-${pad(m)}-${pad(Math.min(dueDay, lastDay))}`);
  }
  return dates;
}

/** What is still owed on one installment, in satang. May be negative. */
export function outstanding(amountDue: number, lateFee: number, paidTotal: number): number {
  return amountDue + lateFee - paidTotal;
}

/**
 * One display label for an installment. PARTIAL wins over OVERDUE: an
 * installment that is past due and partly paid reads as PARTIAL, but still
 * counts toward overdueCount.
 */
export function installmentState(
  amountDue: number,
  lateFee: number,
  paidTotal: number,
  dueDate: string,
  today: string,
): InstallmentState {
  if (outstanding(amountDue, lateFee, paidTotal) <= 0) return "PAID";
  if (paidTotal > 0) return "PARTIAL";
  if (dueDate < today) return "OVERDUE";
  return "UPCOMING";
}

/** How many installments are past due with money still owed. */
export function overdueCount(rows: OverdueRow[], today: string): number {
  return rows.filter(
    (r) => r.dueDate < today && outstanding(r.amountDue, r.lateFee, r.paidTotal) > 0,
  ).length;
}

/** Translate an overdue count into the dashboard warning level. */
export function contractFlag(overdue: number): ContractFlag {
  if (overdue >= 2) return "REPOSSESS_ELIGIBLE";
  if (overdue === 1) return "OVERDUE";
  return "OK";
}

/** Days between the due date and the payment, never negative. */
export function daysLate(dueDate: string, paidOn: string): number {
  const difference = Date.parse(`${paidOn}T00:00:00Z`) - Date.parse(`${dueDate}T00:00:00Z`);
  return Math.max(0, Math.round(difference / 86_400_000));
}

/** Today in the machine's own timezone, as an ISO date string. */
export function todayIso(): string {
  const now = new Date();
  return `${now.getFullYear()}-${pad(now.getMonth() + 1)}-${pad(now.getDate())}`;
}
```

```typescript
/** Checks applied where data enters the system. */

export class ValidationError extends Error {}

/** Return the cleaned 13-digit Thai national ID, or throw. */
export function thaiId(value: string): string {
  const text = String(value).replace(/[-\s]/g, "");
  if (!/^\d{13}$/.test(text)) throw new ValidationError("Thai ID must be 13 digits");

  let total = 0;
  for (let i = 0; i < 12; i++) total += Number(text[i]) * (13 - i);
  if (((11 - (total % 11)) % 10) !== Number(text[12])) {
    throw new ValidationError("Thai ID checksum is wrong");
  }
  return text;
}

/** Throw if a payment amount or date is not acceptable. */
export function payment(amountSatang: number, paidOn: string, today: string): void {
  if (amountSatang <= 0) {
    throw new ValidationError("Payment amount must be greater than zero");
  }
  if (paidOn > today) {
    throw new ValidationError("Payment date cannot be in the future");
  }
}
```

Every query in the application is written with `?` placeholders.
`@tauri-apps/plugin-sql` binds SQLite parameters as `$1, $2, …`, so the
Tauri adapter rewrites them on the way through; `better-sqlite3` takes `?`
directly. No SQL in this codebase contains a literal `?` inside a string,
which is what makes that rewrite safe.

```typescript
export function memoryDb(): Db {
```

`src/db.ts`:

```typescript
/**
 * The database interface and every query in the application.
 *
 * Queries are written with `?` placeholders and take the Db interface, so
 * the same code runs against @tauri-apps/plugin-sql in the application and
 * against better-sqlite3 in tests.
 */

import Database from "@tauri-apps/plugin-sql";

import { SCHEMA } from "./schema";

export interface Db {
  select<T = Record<string, unknown>>(sql: string, params?: unknown[]): Promise<T[]>;
  execute(sql: string, params?: unknown[]): Promise<{ lastInsertId: number }>;
}

/** Rewrite `?` placeholders as `$1, $2, …`, which is how the plugin binds them. */
export function toDollarPlaceholders(sql: string): string {
  let index = 0;
  return sql.replace(/\?/g, () => `$${++index}`);
}

/** An ISO-8601 timestamp for created_at columns. */
export function nowIso(): string {
  return new Date().toISOString().slice(0, 19);
}

/** Open the application database, enable foreign keys, and apply the schema. */
export async function openDatabase(): Promise<Db> {
  const database = await Database.load("sqlite:okrotdee.db");

  const db: Db = {
    async select<T>(sql: string, params: unknown[] = []): Promise<T[]> {
      return database.select<T[]>(toDollarPlaceholders(sql), params);
    },
    async execute(sql: string, params: unknown[] = []) {
      const result = await database.execute(toDollarPlaceholders(sql), params);
      return { lastInsertId: Number(result.lastInsertId ?? 0) };
    },
  };

  await database.execute("PRAGMA foreign_keys = ON");
  for (const statement of SCHEMA.split(";")) {
    if (statement.trim()) await database.execute(statement);
  }
  return db;
}
```

The schema is executed statement by statement because the plugin runs one
statement per call.

`PRAGMA foreign_keys` applies per connection, and the plugin pools
connections, so foreign keys are guaranteed only in the tests, where one
connection is used. The `CHECK` constraints and unique indexes are enforced
per statement and hold in both. This is a known limitation, not an
oversight: the application always writes parents before children, and a
future fix is to move the pragma into the plugin's connection setup.

```typescript
import { createContext, useContext, useEffect, useState, type ReactNode } from "react";

import { openDatabase, type Db } from "./db";
import { DEFAULT_LANG, t as translate, type LangCode } from "./lang";

interface AppValue {
  db: Db;
  lang: LangCode;
  setLang: (code: LangCode) => void;
  t: (key: string) => string;
}

const AppContext = createContext<AppValue | null>(null);

export function AppProvider({ children }: { children: ReactNode }) {
  const [db, setDb] = useState<Db | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [lang, setLangState] = useState<LangCode>(
    (localStorage.getItem("lang") as LangCode) || DEFAULT_LANG,
  );

  useEffect(() => {
    openDatabase().then(setDb, (e) => setError(String(e)));
  }, []);

  const setLang = (code: LangCode) => {
    localStorage.setItem("lang", code);
    setLangState(code);
  };

  if (error) return <p className="flash">{error}</p>;
  if (!db) return <p>{translate("loading", lang)}</p>;

  return (
    <AppContext.Provider
      value={{ db, lang, setLang, t: (key: string) => translate(key, lang) }}
    >
      {children}
    </AppContext.Provider>
  );
}

export function useApp(): AppValue {
  const value = useContext(AppContext);
  if (!value) throw new Error("useApp called outside AppProvider");
  return value;
}
```

```typescript
export interface Client {
  id: number;
  first_name: string;
  last_name: string;
  thai_id: string | null;
  phone: string | null;
  address: string | null;
  note: string | null;
  created_at: string;
}

export type ClientFields = Omit<Client, "id" | "created_at">;

export interface ContractRow {
  id: number;
  client_id: number;
  car_id: number;
  car_price: number;
  down_payment: number;
  installment_amount: number;
  installment_count: number;
  due_day: number;
  first_due_date: string;
  status: string;
  note: string | null;
  created_at: string;
  first_name?: string;
  last_name?: string;
  brand?: string;
  series?: string | null;
  plate_number?: string | null;
}

export async function listClients(db: Db, q?: string): Promise<Client[]> {
  if (q) {
    const like = `%${q}%`;
    return db.select<Client>(
      "SELECT * FROM clients" +
        " WHERE first_name LIKE ? OR last_name LIKE ? OR phone LIKE ? OR thai_id LIKE ?" +
        " ORDER BY first_name, last_name",
      [like, like, like, like],
    );
  }
  return db.select<Client>("SELECT * FROM clients ORDER BY first_name, last_name");
}

export async function getClient(db: Db, id: number): Promise<Client | undefined> {
  return (await db.select<Client>("SELECT * FROM clients WHERE id = ?", [id]))[0];
}

export async function createClient(db: Db, fields: ClientFields): Promise<number> {
  const { lastInsertId } = await db.execute(
    "INSERT INTO clients (first_name, last_name, thai_id, phone, address, note," +
      " created_at) VALUES (?, ?, ?, ?, ?, ?, ?)",
    [
      fields.first_name,
      fields.last_name,
      fields.thai_id,
      fields.phone,
      fields.address,
      fields.note,
      nowIso(),
    ],
  );
  return lastInsertId;
}

export async function updateClient(db: Db, id: number, fields: ClientFields): Promise<void> {
  await db.execute(
    "UPDATE clients SET first_name = ?, last_name = ?, thai_id = ?, phone = ?," +
      " address = ?, note = ? WHERE id = ?",
    [
      fields.first_name,
      fields.last_name,
      fields.thai_id,
      fields.phone,
      fields.address,
      fields.note,
      id,
    ],
  );
}

export async function clientContracts(db: Db, clientId: number): Promise<ContractRow[]> {
  return db.select<ContractRow>(
    "SELECT c.*, cars.brand, cars.series, cars.plate_number FROM contracts c" +
      " JOIN cars ON cars.id = c.car_id WHERE c.client_id = ?" +
      " ORDER BY c.created_at DESC",
    [clientId],
  );
}
```

```typescript
  const { id } = useParams();
  const clientId = id ? Number(id) : null;

  const [client, setClient] = useState<Client | null>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    if (clientId) getClient(db, clientId).then((c) => setClient(c ?? null));
  }, [db, clientId]);

  const onSubmit = async (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const form = new FormData(event.currentTarget);
    const value = (key: string) => ((form.get(key) as string) ?? "").trim() || null;

    try {
      const first_name = value("first_name");
      const last_name = value("last_name");
      if (!first_name || !last_name) {
        throw new ValidationError("First name and last name are required");
      }
      const rawId = value("thai_id");
      const fields = {
        first_name,
        last_name,
        thai_id: rawId ? thaiId(rawId) : null,
        phone: value("phone"),
        address: value("address"),
        note: value("note"),
      };
      if (clientId) {
        await updateClient(db, clientId, fields);
        navigate(`/clients/${clientId}`);
      } else {
        const newId = await createClient(db, fields);
        navigate(`/clients/${newId}`);
      }
    } catch (e) {
      setError(
        e instanceof ValidationError
          ? e.message
          : String(e).includes("UNIQUE")
            ? "That Thai ID is already registered to another client"
            : String(e),
      );
    }
  };
```

```typescript
  car_id: number;
  event_date: string;
  type: string;
  contract_id: number | null;
  note: string | null;
}

const CAR_VALUES = (f: CarFields) => [
  f.brand,
  f.series,
  f.model_year,
  f.color,
  f.plate_number,
  f.registration_no,
  f.chassis_no,
  f.mileage,
  f.cost_price,
  f.asking_price,
  f.note,
];

export async function listCars(db: Db, status?: string, q?: string): Promise<Car[]> {
  let sql = "SELECT * FROM cars WHERE 1 = 1";
  const params: unknown[] = [];
  if (status) {
    sql += " AND status = ?";
    params.push(status);
  }
  if (q) {
    sql += " AND (brand LIKE ? OR series LIKE ? OR plate_number LIKE ?)";
    params.push(`%${q}%`, `%${q}%`, `%${q}%`);
  }
  return db.select<Car>(sql + " ORDER BY brand, series", params);
}

export async function getCar(db: Db, id: number): Promise<Car | undefined> {
  return (await db.select<Car>("SELECT * FROM cars WHERE id = ?", [id]))[0];
}

export async function addCarEvent(
  db: Db,
  carId: number,
  eventDate: string,
  type: string,
  contractId: number | null = null,
  note: string | null = null,
): Promise<void> {
  await db.execute(
    "INSERT INTO car_events (car_id, event_date, type, contract_id, note)" +
      " VALUES (?, ?, ?, ?, ?)",
    [carId, eventDate, type, contractId, note],
  );
}

export async function createCar(db: Db, fields: CarFields): Promise<number> {
  const { lastInsertId } = await db.execute(
    "INSERT INTO cars (brand, series, model_year, color, plate_number," +
      " registration_no, chassis_no, mileage, cost_price, asking_price, note," +
      " status, created_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, 'available', ?)",
    [...CAR_VALUES(fields), nowIso()],
  );
  await addCarEvent(db, lastInsertId, todayIso(), "acquired");
  return lastInsertId;
}

export async function updateCar(db: Db, id: number, fields: CarFields): Promise<void> {
  await db.execute(
    "UPDATE cars SET brand = ?, series = ?, model_year = ?, color = ?," +
      " plate_number = ?, registration_no = ?, chassis_no = ?, mileage = ?," +
      " cost_price = ?, asking_price = ?, note = ? WHERE id = ?",
    [...CAR_VALUES(fields), id],
  );
}

export async function setCarStatus(db: Db, id: number, status: CarStatus): Promise<void> {
  await db.execute("UPDATE cars SET status = ? WHERE id = ?", [status, id]);
}

export async function carEvents(db: Db, carId: number): Promise<CarEvent[]> {
  return db.select<CarEvent>(
    "SELECT * FROM car_events WHERE car_id = ? ORDER BY event_date, id",
    [carId],
  );
}

export async function carContracts(db: Db, carId: number): Promise<ContractRow[]> {
  return db.select<ContractRow>(
    "SELECT c.*, cl.first_name, cl.last_name FROM contracts c" +
      " JOIN clients cl ON cl.id = c.client_id WHERE c.car_id = ?" +

    [carId],
  );
}
```

```typescript
export interface ContractFields {
  client_id: number;
  car_id: number;
  car_price: number;
  down_payment: number;
  installment_amount: number;
  installment_count: number;
  due_day: number;
  first_due_date: string;
  note: string | null;
}

export async function availableCars(db: Db): Promise<Car[]> {
  return db.select<Car>(
    "SELECT * FROM cars WHERE status = 'available' ORDER BY brand, series",
  );
}

export async function listContracts(db: Db, status?: string): Promise<ContractRow[]> {
  let sql =
    "SELECT c.*, cl.first_name, cl.last_name, cars.brand, cars.series," +
    " cars.plate_number FROM contracts c" +
    " JOIN clients cl ON cl.id = c.client_id" +
    " JOIN cars ON cars.id = c.car_id";
  const params: unknown[] = [];
  if (status) {
    sql += " WHERE c.status = ?";
    params.push(status);
  }
  return db.select<ContractRow>(sql + " ORDER BY c.created_at DESC", params);
}

export async function createContract(db: Db, fields: ContractFields): Promise<number> {
  const car = await getCar(db, fields.car_id);
  if (!car || car.status !== "available") throw new Error("That car is not available");

  // Validate before writing: the SQL plugin pools connections, so these
  // statements cannot share one transaction.
  const dates = generateSchedule(
    fields.first_due_date,
    fields.installment_count,
    fields.due_day,
  );

  const { lastInsertId } = await db.execute(
    "INSERT INTO contracts (client_id, car_id, car_price, down_payment," +
      " installment_amount, installment_count, due_day, first_due_date, note," +
      " status, created_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, 'active', ?)",
    [
      fields.client_id,
      fields.car_id,
      fields.car_price,
      fields.down_payment,
      fields.installment_amount,
      fields.installment_count,
      fields.due_day,
      fields.first_due_date,
      fields.note,
      nowIso(),
    ],
  );

  for (const [index, dueDate] of dates.entries()) {
    await db.execute(
      "INSERT INTO installments (contract_id, seq, due_date, amount_due)" +
        " VALUES (?, ?, ?, ?)",
      [lastInsertId, index + 1, dueDate, fields.installment_amount],
    );
  }

  await setCarStatus(db, fields.car_id, "on_contract");
  await addCarEvent(db, fields.car_id, todayIso(), "contract_started", lastInsertId);
  return lastInsertId;
}
```

```typescript
export interface InstallmentRow {
  id: number;
  contract_id: number;
  seq: number;
  due_date: string;
  amount_due: number;
  late_fee: number;
  paid_total: number;
}

export interface Payment {
  id: number;
  installment_id: number;
  paid_on: string;
  amount: number;
  method: string | null;
  note: string | null;
  created_at: string;
}

const INSTALLMENTS_SQL = (where: string) =>
  "SELECT i.*, COALESCE(SUM(p.amount), 0) AS paid_total FROM installments i" +
  " LEFT JOIN payments p ON p.installment_id = i.id" +
  ` WHERE ${where} GROUP BY i.id ORDER BY i.seq`;

/** A database row in the shape money.ts takes. */
export function overdueRow(i: InstallmentRow): OverdueRow {
  return {
    dueDate: i.due_date,
    amountDue: i.amount_due,
    lateFee: i.late_fee,
    paidTotal: i.paid_total,
  };
}

export async function getContract(db: Db, id: number): Promise<ContractRow | undefined> {
  return (
    await db.select<ContractRow>(
      "SELECT c.*, cl.first_name, cl.last_name, cars.brand, cars.series," +
        " cars.plate_number FROM contracts c" +
        " JOIN clients cl ON cl.id = c.client_id" +
        " JOIN cars ON cars.id = c.car_id WHERE c.id = ?",
      [id],
    )
  )[0];
}

export async function installmentsFor(db: Db, contractId: number): Promise<InstallmentRow[]> {
  return db.select<InstallmentRow>(INSTALLMENTS_SQL("i.contract_id = ?"), [contractId]);
}

export async function getInstallment(db: Db, id: number): Promise<InstallmentRow | undefined> {
  return (await db.select<InstallmentRow>(INSTALLMENTS_SQL("i.id = ?"), [id]))[0];
}

export async function paymentsFor(db: Db, installmentId: number): Promise<Payment[]> {
  return db.select<Payment>(
    "SELECT * FROM payments WHERE installment_id = ? ORDER BY paid_on, id",
    [installmentId],
  );
}

export async function setLateFee(db: Db, installmentId: number, lateFee: number): Promise<void> {
  await db.execute("UPDATE installments SET late_fee = ? WHERE id = ?", [
    lateFee,
    installmentId,
  ]);
}

export async function addPayment(
  db: Db,
  installmentId: number,
  paidOn: string,
  amount: number,
  method: string | null,
  note: string | null,
): Promise<void> {
  await db.execute(
    "INSERT INTO payments (installment_id, paid_on, amount, method, note, created_at)" +
      " VALUES (?, ?, ?, ?, ?, ?)",
    [installmentId, paidOn, amount, method, note, nowIso()],
  );
}

/** Close the contract and mark the car sold once nothing is outstanding. */
export async function completeContractIfPaid(db: Db, contractId: number): Promise<boolean> {
  const rows = await installmentsFor(db, contractId);
  if (rows.some((r) => outstanding(r.amount_due, r.late_fee, r.paid_total) > 0)) {
    return false;
  }
  const contract = await getContract(db, contractId);
  if (!contract || contract.status !== "active") return false;

  await db.execute("UPDATE contracts SET status = 'completed' WHERE id = ?", [contractId]);
  await setCarStatus(db, contract.car_id, "sold");
  await addCarEvent(db, contract.car_id, todayIso(), "contract_completed", contractId);
  return true;
}
```

```typescript
import { useEffect, useState, type FormEvent } from "react";
import { useNavigate, useParams } from "react-router-dom";

import { useApp } from "../context";
import {
  addPayment,
  completeContractIfPaid,
  getContract,
  getInstallment,
  setLateFee,
  type ContractRow,
  type InstallmentRow,
} from "../db";
import { daysLate, formatBaht, outstanding, toSatang, todayIso } from "../money";
import { payment as validatePayment, ValidationError } from "../validate";

export default function PaymentForm() {
  const { db, t } = useApp();
  const navigate = useNavigate();
  const installmentId = Number(useParams().id);
  const [installment, setInstallment] = useState<InstallmentRow | null>(null);
  const [contract, setContract] = useState<ContractRow | null>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    getInstallment(db, installmentId).then(async (row) => {
      setInstallment(row ?? null);
      if (row) setContract((await getContract(db, row.contract_id)) ?? null);
    });
  }, [db, installmentId]);

  if (!installment || !contract) return <p>{t("loading")}</p>;

  const balance = outstanding(
    installment.amount_due,
    installment.late_fee,
    installment.paid_total,
  );
  const late = daysLate(installment.due_date, todayIso());

  const onSubmit = async (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const form = new FormData(event.currentTarget);
    const text = (key: string) => ((form.get(key) as string) ?? "").trim();
    setError(null);
    try {
      const paidOn = text("paid_on");
      const amount = toSatang(text("amount"));

        <p className="flash">
          {late} {t("days_late")}
        </p>
      )}
      {error && <p className="flash">{error}</p>}
      <form className="stack" onSubmit={onSubmit}>
        <label>
          {t("payment_date")}
          <input type="date" name="paid_on" defaultValue={todayIso()} required />
```

```typescript
export interface DashboardRow extends InstallmentRow {
  first_name: string;
  last_name: string;
  brand: string;
  series: string | null;
  plate_number: string | null;
}

/** Every installment on every active contract, with who and what it is for. */
export async function activeInstallments(db: Db): Promise<DashboardRow[]> {
  return db.select<DashboardRow>(
    "SELECT i.*, COALESCE(SUM(p.amount), 0) AS paid_total," +
      " cl.first_name, cl.last_name, cars.brand, cars.series, cars.plate_number" +
      " FROM installments i" +
      " JOIN contracts c ON c.id = i.contract_id" +
      " JOIN clients cl ON cl.id = c.client_id" +
      " JOIN cars ON cars.id = c.car_id" +
      " LEFT JOIN payments p ON p.installment_id = i.id" +
      " WHERE c.status = 'active'" +
      " GROUP BY i.id ORDER BY i.due_date, i.id",
  );
}

/** Satang received between two ISO dates, inclusive. */
export async function collectedBetween(db: Db, start: string, end: string): Promise<number> {
  const rows = await db.select<{ total: number }>(
    "SELECT COALESCE(SUM(amount), 0) AS total FROM payments WHERE paid_on BETWEEN ? AND ?",
    [start, end],
  );
  return rows[0]?.total ?? 0;
}
```

```typescript
/** Database backup. The database lives where staff cannot reach it, so this
 * is the application's job. */

import { appConfigDir, join } from "@tauri-apps/api/path";
import { save } from "@tauri-apps/plugin-dialog";
import { copyFile, exists, mkdir, readDir, remove } from "@tauri-apps/plugin-fs";
import { openPath } from "@tauri-apps/plugin-opener";

import { todayIso } from "./money";

const KEEP = 30;

async function paths() {
  const dir = await appConfigDir();
  return {
    database: await join(dir, "okrotdee.db"),
    backups: await join(dir, "backups"),
  };
}

/** Copy today's database into backups/, then prune to the newest 30 copies. */
export async function startupBackup(): Promise<void> {
  const { database, backups } = await paths();
  if (!(await exists(database))) return;
  if (!(await exists(backups))) await mkdir(backups, { recursive: true });

  const target = await join(backups, `okrotdee-${todayIso()}.db`);
  await copyFile(database, target);

  const entries = (await readDir(backups))
    .filter((e) => e.name?.startsWith("okrotdee-") && e.name.endsWith(".db"))
    .map((e) => e.name!)
    .sort();
  for (const name of entries.slice(0, Math.max(0, entries.length - KEEP))) {
    await remove(await join(backups, name));
  }
}

/** Copy the database somewhere the staff choose. Returns the path, or null. */
export async function backupTo(): Promise<string | null> {
  const { database } = await paths();
  const target = await save({ defaultPath: `okrotdee-${todayIso()}.db` });
  if (!target) return null;
  await copyFile(database, target);
  return target;
}

/** Open the backup folder in Finder or Explorer. */
export async function showBackups(): Promise<void> {
  const { backups } = await paths();
  if (!(await exists(backups))) await mkdir(backups, { recursive: true });
  await openPath(backups);
}
```

## Notes for the implementer

- **Money never touches a float.** Parse with `toSatang`, store the integer,
  display with `formatBaht`. Dividing by 100 outside `money.ts` is a bug.
- **Dates are ISO strings.** `"2026-09-15" < "2026-10-01"` is the comparison
  this codebase uses. Constructing a `Date` from a date-only string parses it
  as UTC and shifts the day in Thai time — that is the bug this rule exists
  to prevent.
- **Status is derived, never stored.** The only status fields written are
  `contracts.status` and `cars.status`, and only by an explicit staff action
  or by `completeContractIfPaid`.
- **The application never repossesses anything.** It shows
  `REPOSSESS_ELIGIBLE` and waits for a person to click.
- **All SQL lives in `db.ts`,** written with `?` placeholders. Components
  call query functions; they never write SQL.
- **`db.ts` never imports Tauri outside `openDatabase`.** That is what keeps
  every query testable in Node.
- **No business logic in Rust.** `src-tauri/src/lib.rs` registers plugins.
